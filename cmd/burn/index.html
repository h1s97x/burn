burn.

把一段文字变成一次性链接。被读走一次，就永远消失。

上传

# 默认 TTL {{DEFAULT_TTL}}
echo "密码" | curl -T - {{BASE_URL}}

# 自定存活时间（最长 {{MAX_TTL}}）
cat ~/.ssh/id_ed25519 | curl -T - "{{BASE_URL}}/?ttl=10m"

返回一条链接：

{{BASE_URL}}/k3f9x2vq0w7m4n8z

读取

# 读走即销毁，第二次访问就是 404
curl {{BASE_URL}}/k3f9x2vq0w7m4n8z

浏览器打开会先看到一个确认按钮，点了才真正销毁 —— 免得聊天软件预览链接时替你烧掉秘密。

alias

# Linux / macOS
alias burn='curl -T - {{BASE_URL}}'
echo "token" | burn
# Windows PowerShell
function burn { $input | curl -T - {{BASE_URL}} }

它的边界

  • 内容原样落盘，靠 0700 目录权限和「读走即删除」保护，不做加密存储。
  • 读取是原子的 rename，并发请求只有一个能拿到内容。
  • 过期由服务端定期清扫，最短 1 秒，最长 {{MAX_TTL}}。
  • 不保留任何访问日志，不记录是谁读的。
